# 약관·개인정보 법률 검토 체크리스트

현재 약관·개인정보 본문은 출시 전 초안(policyDraft 표기)이다.
공개 가입 전에 아래를 법무 검토로 확정해야 한다.

## 1. 운영자 정보 확정 (3개 언어 동일 반영)

- [ ] 상호명·대표자·사업자번호·주소·연락처 ([상호명] 플레이스홀더 교체)
- [ ] 개인정보 보호책임자 성명·연락처
- [ ] 호스팅 리전, 준거법·관할 법원

## 2. 데이터 인벤토리 대조 (실제 스키마 기준)

- [ ] webapp.accounts: 아이디·메일·성명·생년월일·성별(직접입력 포함)·복구 메일·전화·언어·비밀번호 해시·세션 토큰 해시
- [ ] webapp.sessions: 토큰 해시·만료·최근접속
- [ ] webapp.mail_connections: 연결 식별자·토큰(암호화)
- [ ] webapp.rate_limits: 해시 식별자·요청 기록
- [ ] crawl/catalog/query 스키마: 수집 문서·쿼리 로그 보관 기간 확정
- [ ] 보관 기간·파기 절차·법적 근거 항목별 매핑

## 3. 쟁점 조항

- [ ] 최소 가입 연령 만 14세 (생년월일 수집 근거 명시)
- [ ] 복구 정보의 목적 외 이용 금지, 계정 삭제 시 처리
- [ ] 연결 메일함 데이터는 제공업체 보관 — 위탁·제3자 제공 조항
- [ ] DSAR(열람·삭제) 접수창구와 처리 기한, 이중 승인 절차 연계
- [ ] 검색 기록 기기 내 저장(opt-in) 설명과 브라우저 저장소 고지
- [ ] 광고·오가닉 분리 선언과 실제 동작 일치 확인
- [ ] 과금 개시 시 유료약관·환불 정책 별도 부속서

## 4. 산출물

- [ ] 검토 의견서 보관, 변경 이력 관리 시작
