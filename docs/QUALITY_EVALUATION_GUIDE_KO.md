## 1. 평가 목적 및 원칙

OpenPortal Search의 랭킹 품질은 기계적 메트릭뿐만 아니라 실제 사용자의 정보 요구를 충족하는지에 대한 객관적인 인적 평가(Human Relevance Evaluation)를 통해 지속적으로 검증되어야 합니다.

### 핵심 평가 원칙
1. **블라인드 평가 (Double-Blind Evaluation):**
   - 평가자는 해당 검색 결과가 어떤 알고리즘(BM25, Nori 형태소 분석기, RRF 하이브리드, 재랭킹 모델 등)에서 산출되었는지 알 수 없습니다.
2. **독립 평가 (Rater Independence):**
   - 동일한 (검색어, 검색 결과) 쌍에 대해 최소 2명의 독립된 전문 평가자가 상호 협의 없이 독립적으로 점수를 부여합니다.
3. **일치도 검증 (Inter-Rater Reliability):**
   - 두 평가자 간의 코헨 카파 계수(Cohen's Kappa, $\kappa$)가 0.70 이상이어야 평가 세트가 신뢰할 수 있는 것으로 인정됩니다.
4. **심각한 불일치 중재 (Senior Arbitration):**
   - 두 평가자의 등급 차이가 2단계 이상(예: Vital vs Marginal/Irrelevant)인 경우, 시니어 품질 심사역이 중재 판정을 진행합니다.

## 2. 4단계 적합성 등급 (Relevance Rubric)

| 등급 | 영문 명칭 | 정의 및 판정 기준 | 한국어 검색 예시 |
|:---:|:---|:---|:---|
| **3** | **Vital** | 사용자가 찾고자 하는 결정적인 대표 문서. 공식 웹사이트 홈, 단일 명확한 질문의 공식 가이드, 네비게이션 목적어의 직행 페이지. | `국세청 홈택스` 검색 시 국세청 홈택스 공식 메인 페이지(`hometax.go.kr`) |
| **2** | **Relevant** | 사용자의 검색 의도를 직접적이고 충실하게 만족시키는 유용한 문서. 핵심 내용을 명확하고 최신 정보로 서술함. | `소득세율 계산법` 검색 시 국세청 소득세 안내 페이지 또는 정확한 세무 포털 설명 |
| **1** | **Marginal** | 부차적이거나 간접적으로만 관련된 문서. 불완전한 요약, 관련 키워드가 언급되나 핵심 답을 주지 못함, 또는 다소 오래된 정보. | `소득세율 계산법` 검색 시 5년 전 소득세법 개정안 기사 또는 세무사 사무실 단순 소개글 |
| **0** | **Irrelevant** | 검색 의도와 무관한 문서. 키워드 스터핑/스팸, 깨진 링크(404), 오해의 소지가 있는 허위 정보, 멀웨어 의심 사이트. | `소득세율 계산법` 검색 시 불법 카지노 배너가 걸린 스팸 블로그나 무관한 게임 공략글 |

## 3. 의도(Intent)별 평가 세부 지침

### 3.1 정보성 질의 (Informational)
- **질의 형태:** `~방법`, `~뜻`, `~원인`, `어떻게`, `원리`
- **평가 초점:** 본문 요약문(Snippet)의 정보 충실도, 최신성, 공신력.
- **감점 요인:** 질문과 무관한 일반론 반복, 기계 번역된 부자연스러운 문장, 광고 과다 노출.

### 3.2 탐색성 질의 (Navigational)
- **질의 형태:** 브랜드명, 도메인명, 기관명, 서비스명 (`네이버`, `오픈포털`, `대한항공`, `gmarket.co.kr`)
- **평가 초점:** 사용자가 찾는 바로 그 공식 사이트가 Rank 1에 위치해야 Vital(3).
- **엄격 규칙:** 사칭 사이트, 제3자 피싱/리다이렉트 링크는 무조건 Irrelevant(0) 처리.

### 3.3 거래성 질의 (Transactional)
- **질의 형태:** `구매`, `가격`, `예약`, `할인`, `다운로드`, `최저가`
- **평가 초점:** 실제 구매/예약/다운로드가 가능한 랜딩 페이지 연결 여부.
- **감점 요인:** 품절/서비스 종료 페이지, 결제 링크가 없는 낚시성 페이지.

### 3.4 지역성 질의 (Local)
- **질의 형태:** `강남역 맛집`, `종로 약국`, `부산 호텔`, `근처 병원`
- **평가 초점:** 검색 대상 지역과 정확히 일치하는 지리적 적합성, 영업 상태.

## 4. 블라인드 인적 판정 프로세스 워크플로우

```mermaid
flowchart TD
    Q[골든 쿼리셋 추출] --> Blind[알고리즘 메타데이터 제거 및 블라인드 처리]
    Blind --> JudgeA[평가자 A 독립 채점 0~3]
    Blind --> JudgeB[평가자 B 독립 채점 0~3]
    JudgeA --> Compare{채점 일치도 비교}
    JudgeB --> Compare
    Compare -->|차이 0 또는 1| Finalize[보수적 최소 등급으로 최종 확정]
    Compare -->|차이 >= 2| Arbitrate[시니어 품질 심사역 중재]
    Arbitrate --> Finalize
    Finalize --> Kappa[코헨 카파 계수 산출]
    Kappa --> MetricCalc[NDCG@10 및 MRR@10 계산]
```
