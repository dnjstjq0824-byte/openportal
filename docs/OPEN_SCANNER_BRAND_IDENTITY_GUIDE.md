## 2. Core Brand Philosophy: Search-to-Action Ecosystem

Open Scanner is fundamentally distinct from legacy search engines: it is not a mere link index, ad gate, or static directory. It is a unified global digital ecosystem connecting information, content, commerce, services, engineering, people, and business.

### 2.1 The 5-Phase Search-to-Action Lifecycle
```
┌───────────┐     ┌────────────┐     ┌───────────┐     ┌──────────────┐     ┌──────────┐
│  Search   │ ──> │  Discover  │ ──> │  Connect  │ ──> │  Experience  │ ──> │  Create  │
│ 무엇이든 검색 │     │  모든 것 발견 │     │  글로벌 연결 │     │   디지털 경험  │     │  가치 창출  │
└───────────┘     └────────────┘     └───────────┘     └──────────────┘     └──────────┘
```
- **Search (시작):** 전 세계의 방대한 웹, 실시간 신디케이션 뉴스, 다국어 지식을 편향 없이 공정하게 검색.
- **Discover (과정):** 새로운 멀티미디어 콘텐츠, AI 심층 추론, 최적 가격 상품, 글로벌 기회를 탐색 및 발견.
- **Connect (연결):** 단일 통합 계정과 E2EE 보안 인프라를 바탕으로 사용자, 서비스 제공자, 플랫폼을 신뢰로 결합.
- **Experience (경험):** 분산 스트리밍, 웹메일, 초저지연 앱, 라이브 커뮤니케이션을 즉각 실행.
- **Create (결과):** 개발자 API, 분산 클라우드, 독립 콘텐츠 유통을 통해 새로운 상업적·문화적 가치를 창출.

> **"검색은 시작이고, 발견은 과정이며, 실행은 결과다."**

## 5. Global Brand Touchpoint Deployment Guidelines

슬로건은 반드시 다음 12개 핵심 터치포인트에 일관되게 적용된다:

1. **메인 홈페이지 (Home Hero):** 대형 로고 하단에 공식 영문 슬로건 및 한국어 해석, Search-to-Action 5단계 뱃지 배치.
2. **와플 메뉴 (App Launcher):** 상단 배너에 "Search-to-Action Ecosystem · Search Anything. Discover Everything. Do Anything." 고지 및 각 타일에 Search/Discover/Action 필러 태그 표기.
3. **통합 계정 모달 (Unified Account Modal):** 헤더 브랜드 마크에 소형 슬로건 결합.
4. **발송 이메일 템플릿:** 인증 PIN 및 비밀번호 재설정 이메일 푸터에 공식 슬로건 및 한국어 해석 각인.
5. **글로벌 푸터:** "Search Anything. Discover Everything. Do Anything." 스트립 및 "브랜드 철학 (Search-to-Action)" 모달 링크 제공.
6. **브랜드 소개 모달:** Search → Discover → Connect → Experience → Create 및 30개 플랫폼 통합 철학 인터랙티브 브리핑.
7. **개발자 콘솔 & API 문서:** OpenAPI 3.1 명세 상단 헤더에 슬로건 기재.
8. **글로벌 SEO 메타데이터:** `index.html` OpenGraph / Twitter Cards Description에 공식 슬로건 반영.
9. **운영자 관제 타워:** 실시간 텔레메트리 헤더에 브랜드 미션 명시.
10. **앱 아이콘 & 스플래시:** 모바일 뷰포트 맞춤형 슬로건 축약형("Search · Discover · Do").
11. **오픈소스 & 깃허브 저장소 README:** 공식 프로젝트 브랜드 슬로건 반영.
12. **이용약관 및 개인정보처리방침:** 서비스 목적 정의에 "Search-to-Action 디지털 생태계 제공" 명문화.

## 6. Prohibited Practices & Compliance

1. **슬로건 변형 금지:** "Search Anything. Discover Everything. Do Anything." 외의 임의 슬로건(예: "All about search", "Beyond search" 단독 사용 등)을 메인 슬로건으로 대체할 수 없다.
2. **타사 상표권 침해 금지:** 타사(Google, Apple, YouTube, Netflix 등)의 워드마크, UI를 모방하거나 혼동을 유발하는 시각 요소를 일체 배제한다.
3. **허위/과장 광고 금지:** 현재 구현되지 않은 외부 제휴 기능을 완료된 것처럼 표기하지 않으며, "세계 1위" 등의 주장은 객관적 입증 전까지 비전 차원에서만 다룬다.
4. **Fail-Closed 보안 원칙:** Search-to-Action 연동 과정에서 외부 자격증명이 없는 서드파티 확장은 반드시 `BLOCKED_EXTERNAL` 상태를 유지하고 사용자 인증 정보를 불법 수집하지 않는다.
