# Phase 0 경쟁 기능·권리 경계 — 002

아래는 경쟁 제품을 조사할 때 적용할 **기능 비교 틀**이다. 현재 상용 제품의 지원 여부나 우열을 확인했다는 뜻이 아니다.
외부 서비스의 기능·약관은 출시 전 담당자가 공식 자료와 법무 검토로 확인해야 한다.

| 기능 축 | 범용 검색 포털 비교 범위 | OpenPortal Phase 0 | 최종 목표 |
|---|---|---|---|
| 웹 검색 | Google/Bing의 공개 검색 경험 | 합성 자체 색인 검색 | 허가된 자체 수집/색인 |
| 지역·콘텐츠 탭 | 네이버/Google의 뉴스·지도·쇼핑 경험 | 미구현 | 계약된 원천과 삭제 전파 |
| 개인정보 | 동의·보관·삭제 UX | 이력 비수집 | 목적별 opt-in과 삭제 |
| 광고 | organic/sponsored 분리 | 광고 없음 | 광고 표시·원장 감사 |
| AI 요약 | 출처·불확실성 UX | 미구현 | 권리 검증 RAG 및 독립 평가 |

Google·네이버·Bing 명칭은 비교 대상 식별에만 쓴다. 로고·상표·독점 자산·검색결과 색인을 복제하지 않는다.
OpenPortal 명칭/도메인 사용권, 수집 대상 허가, 뉴스/미디어 재배포와 지도 라이선스는 승인되지 않았다.
지도/뉴스/결제 활성화는 계약·승인 없이 차단한다. 허용 정책과 출처 기록 없는 문서는 수집하지 않는다.
robots 허용은 저작권 라이선스를 대신하지 않는다. fixture는 example.org의 실제 페이지를 수집한 것이 아니다.
라이선스 검토 기록: 소스, 권리자, 허용 용도, 보유기한, 삭제 연락처, 검토자, 승인일을 출시 전 요구한다.
